## Conventions

- **Naming**: Verbatim filenames from the originating document (no rename). The sibling `.md` in the parent folder carries a `source:` frontmatter pointer to the PDF name in this folder.
- PDFs are authoritative; `.md` conversions in the parent folder are summary-fidelity only.
- Do not edit PDFs. Replace-only if a new revision supersedes the file — and then bump the parent `.md` changelog with the version diff.
