## Approved Intended Use

### FDA-Cleared Intended Use Statement

> The MicroDose Elite (Model SP-6500) is intended for precise controlled delivery of medications and fluids via syringe in hospital settings, including critical care, neonatal, pediatric, and general acute care units. The device is designed for use by qualified healthcare professionals for adult, pediatric, and neonatal patients requiring precise low-volume infusions. The device features enhanced safety features, extended battery life, and advanced connectivity for integrated clinical workflows.

**Patient Population**:
- Adults (≥18 years)

- Neonates (including premature infants ≥500g)

### Clinical Studies Supporting Clearance

#### Study 1: Enhanced Flow Rate Accuracy Study
- **Study Design**: Bench testing and clinical validation
- **Test Conditions**: Multiple syringe sizes (5-60 mL), flow rates (0.01-500 mL/hr), extended duration
- **Primary Endpoint**: Flow rate accuracy at ultra-low rates (0.01-1 mL/hr)
- **Results**:
  - Flow rate accuracy: ±2.3% (improved from ±2.8% in predicate)
  - VTBI accuracy: ±0.003 mL at low volumes
  - Bolus accuracy: ±2.8%
  - Occlusion alarm response time: <20 seconds at all flow rates

## Contraindications

### Absolute Contraindications

1. **Medication Factors**:
   - Medications requiring flow rates >500 mL/hr
   - Medications incompatible with polycarbonate syringes
   - Vesicant medications via peripheral IV (without appropriate monitoring)

2. **Clinical Conditions**:
   - Emergency resuscitation requiring rapid bolus infusion (use manual push)
   - Patients requiring MRI scanning (device is not MRI-safe)

3. **Device Factors**:
   - Use with non-compatible syringes (not on approved list)
   - Use with damaged, cracked, or expired syringes
   - Use in explosive atmospheres or near flammable anesthetics

### Relative Contraindications (Use with Caution)

- Extremely low birth weight infants (<500g) - requires additional monitoring
- High-risk medications (chemotherapy, vasoactives) - requires drug library activation
- Home infusion - not approved for home use (hospital/facility use only)

## Warnings and Precautions

### Device-Specific Warnings

1. **Syringe Loading**:
   - Ensure syringe is correctly identified by device before starting infusion
   - Verify syringe size matches drug library selection
   - Inspect syringe for cracks, air bubbles, or particulate matter
   - Ensure syringe plunger moves freely without binding
   - Device will reject damaged or non-approved syringes

2. **Programming Errors**:
   - Verify all programmed parameters before initiating therapy
   - Use independent double-check for high-risk medications
   - Pay special attention to decimal point entry (potential for 10x/100x dose errors at low rates)
   - Verify correct units (mL/hr vs mL/min)
   - Review drug library alerts before overriding soft limits

3. **Free-Flow Prevention**:
   - Always ensure syringe is properly clamped by device before removing from pole
   - Never manually advance syringe plunger while in device
   - Verify syringe clamp is engaged during loading and removal
   - Use anti-reflux valves for central lines in neonates
   - Device will alarm if syringe clamp disengages

4. **Occlusion Response**:
   - Respond immediately to occlusion alarms - increased pressure can cause syringe fracture or line separation
   - Do not increase occlusion limit above recommended setting for medication type
   - Inspect entire infusion line for kinks, clamps, or obstructions
   - For neonatal patients, use low occlusion settings (0.3-3 psi)

5. **Air Detection**:
   - Device detects air in syringe barrel but not in downstream tubing
   - Prime all tubing completely before connecting to patient
   - Use in-line filters for high-risk patients (neonates, central lines, arterial)

6. **Battery Management**:
   - Connect to AC power whenever available, especially for critical medications
   - Monitor battery health status - replace device if health <80%
   - Do not use device with damaged, swollen, or overheating battery
   - For multi-pump stacks, verify all pumps have adequate battery charge
   - Device will provide early warning for battery degradation

7. **Drug Library**:
   - Update drug library regularly per institutional formulary changes
   - Verify drug library includes neonatal/pediatric dosing limits
   - Document all hard limit overrides with physician order
   - Soft limit alerts should trigger clinical review before override
   - Clinical decision support features require proper configuration

8. **Multi-Pump Stacking**:
   - Maximum 8 pumps in a stack
   - Verify stack stability before use - secure to pole or use stabilizing base
   - Master pump controls shared functions - verify master pump battery status
   - Individual pumps maintain independent delivery if master pump fails
   - Larger stacks (>6 pumps) require stabilizing base accessory

9. **Wireless Connectivity**:
   - Do not rely solely on wireless alarms - maintain direct patient monitoring
   - Verify wireless connection status before leaving patient bedside
   - Wireless functionality does not replace bedside alarm monitoring
   - EMR integration requires proper configuration and validation
   - Verify data transmission to EMR during setup

### Precautions

- **Training**: All users must complete device training before clinical use; specialized training for NICU use and advanced features
- **Maintenance**: Perform preventive maintenance per manufacturer schedule (every 12 months or 2,000 runtime hours, whichever comes first)
- **Cleaning**: Use only approved cleaning agents; avoid alcohol >70% and bleach >0.5%; cleanable with quaternary ammonium compounds
- **Syringe Compatibility**: Use only approved syringe brands listed in IFU; device will warn if incompatible syringe detected
- **Environmental**: Protect device from moisture, extreme temperatures, and physical damage
- **Drop Protection**: While device is drop-tested, inspect and run self-test after any drop >0.5 meters
- **Neonatal Use**: Extra caution required for neonates - use low occlusion limits, verify drug library neonatal mode active
- **Software Updates**: Install software updates per manufacturer recommendations; updates may include critical safety enhancements
- **Battery Replacement**: Battery is not user-replaceable - contact manufacturer for battery service

✅ "96% user satisfaction in clinical studies"

**Cannot Claim** (not substantiated or false):
❌ "Eliminates medication errors" (too absolute)
❌ "Best syringe pump on the market" (superiority claim without comprehensive head-to-head data)
❌ "FDA-approved" (it's FDA-cleared, not approved)
❌ "Zero programming errors" (false)
❌ "100% accurate" (has ±5%/±0.01 mL tolerance)
❌ "Prevents all free-flow events" (multiple layers but not absolute)
❌ "Lifetime battery" (battery degrades over time)
❌ Off-label uses not in cleared intended use (e.g., home use)

### Key Messaging Guardrails

1. **Must Align with Intended Use**: All marketing must reflect FDA-cleared intended use
2. **Cannot Promote Off-Label**: No promotion for home use or non-approved settings
3. **Must Include Balance**: Benefits AND limitations must be presented fairly
4. **Must Be Substantiated**: All claims must have supporting data from studies or specifications
5. **Cannot Minimize Risks**: Programming errors, free-flow risk, occlusion risks, and battery issues must be acknowledged
6. **Battery Issue Transparency**: March 2023 battery recall must be mentioned when discussing battery performance; emphasize corrective actions
7. **Neonatal Use**: Extra emphasis on specialized training and drug library configuration for NICU applications
8. **Cannot Compare Without Data**: Competitive claims require head-to-head studies
9. **EMR Integration**: Cannot claim seamless integration with all EMRs; must specify supported systems
