## Approved Intended Use

### FDA-Cleared Intended Use Statement

> The FlexFlow Pro (Model IP-5000) is intended for controlled delivery of intravenous fluids, medications, and nutrients through programmable infusion rates in hospital and ambulatory care settings. The device is designed for use by qualified healthcare professionals for adult and pediatric patients.

### Additional Intended Use Details

**Patient Population**:
- Adults (≥18 years)
- Pediatric patients (≥2 years, ≥10 kg)
- Neonates (≥1 kg, with appropriate care settings)
- Geriatric patients

- Intensive Care Units (ICU)
- Medical-Surgical Units
- Emergency Departments
- Operating Rooms
- Post-Anesthesia Care Units (PACU)
- Ambulatory Infusion Centers
- Home Care (with appropriate supervision)

**Administration Routes**:
- Intravenous (IV) - peripheral and central lines

## Contraindications

### Absolute Contraindications

1. **Medication Factors**:
   - Medications requiring precise flow control beyond device specifications
   - Medications known to be incompatible with PVC tubing
   - Vesicant medications via peripheral IV (without appropriate monitoring)

2. **Clinical Conditions**:
   - Situations requiring flow rates outside device range (>1,200 mL/hr)
   - Emergency resuscitation requiring rapid bolus infusion
   - Patients requiring MRI scanning (device is not MRI-safe)

3. **Device Factors**:
   - Use with non-compatible IV administration sets
   - Use with damaged or expired tubing
   - Use in explosive atmospheres or near flammable anesthetics

### Relative Contraindications (Use with Caution)

- Neonates <1 kg body weight (requires additional monitoring)
- Patients with air embolism risk (use micro-bore tubing)
- High-risk medications (chemotherapy, vasoactives) - requires drug library activation
- Home infusion (requires appropriate patient/caregiver training)

## Warnings and Precautions

### Device-Specific Warnings

1. **Programming Errors**:
   - Verify all programmed parameters before initiating therapy
   - Use independent double-check for high-risk medications
   - Pay special attention to decimal point entry (potential for 10x dose errors)
   - Ensure correct drug is selected from drug library

2. **Free-Flow Risk**:
   - Always ensure IV set is properly loaded in pump mechanism
   - Verify door is fully closed and latched before starting infusion
   - Never rely solely on tubing clamps - use pump door-closed interlock
   - Inspect anti-siphon valve for proper function during setup

3. **Alarm Response**:
   - Respond immediately to all alarms
   - Do not disable or silence alarms except per device instructions
   - Test all alarms before initial use
   - High-priority alarms require immediate investigation

4. **Air-In-Line Detection**:
   - Air detector may not detect micro-bubbles <50 microliters
   - Use in-line filters for high-risk patients (central lines, arterial)
   - Verify air detector is positioned correctly on tubing

5. **Battery Management**:
   - Connect to AC power whenever available
   - Replace device if battery life is significantly reduced
   - Do not use device with damaged or swollen battery
   - Ensure adequate battery charge for intended infusion duration

6. **Drug Library**:
   - Update drug library regularly per institutional formulary changes
   - Verify drug library version matches current institutional protocols
   - Document all hard limit overrides with physician order
   - Soft limit alerts should not be routinely bypassed

7. **Wireless Connectivity**:
   - Do not rely solely on wireless alarms - maintain direct patient monitoring
   - Verify wireless connection status before leaving patient bedside
   - Wireless functionality does not replace bedside alarm monitoring

### Precautions

- **Training**: All users must complete device training before clinical use
- **Maintenance**: Perform preventive maintenance per manufacturer schedule (every 12 months or 2,000 runtime hours)
- **Cleaning**: Use only approved cleaning agents - avoid alcohol >70% and bleach >0.5%
- **Tubing Compatibility**: Use only manufacturer-approved IV administration sets
- **Environmental**: Protect device from moisture, extreme temperatures, and physical damage
- **Drop Protection**: Device may malfunction if dropped - inspect and test after any drop
- **Stacking**: Maximum 4 pumps in a stack - verify stability before use

## Marketing and Promotional Considerations

### Approved Marketing Claims

**Can Claim** (with substantiation):
✅ "6+ hours battery life for uninterrupted therapy"
✅ "Comprehensive drug library with 300+ medications"
✅ "Wireless EMR integration for seamless documentation"
✅ "Advanced dose error reduction system (DERS)"
✅ "Air-in-line detection ≥50 microliters"
✅ "Suitable for adult, pediatric, and neonatal patients"
✅ "99.8% alarm accuracy in clinical studies"

**Cannot Claim** (not substantiated or false):
❌ "Eliminates medication errors" (too absolute)
❌ "Best infusion pump on the market" (superiority claim without head-to-head data)
❌ "FDA-approved" (it's FDA-cleared, not approved)
❌ "Zero programming errors" (false)
❌ "Prevents all air embolisms" (air detection has limitations)
❌ Off-label uses not in cleared intended use

### Key Messaging Guardrails

1. **Must Align with Intended Use**: All marketing must reflect FDA-cleared intended use
2. **Cannot Promote Off-Label**: No promotion for uses outside approved indications
3. **Must Include Balance**: Benefits AND limitations must be presented fairly
4. **Must Be Substantiated**: All claims must have supporting data
5. **Cannot Minimize Risks**: Free-flow risk and programming errors must be acknowledged
6. **Cannot Compare Without Data**: Competitive claims require head-to-head studies
7. **Drug Library Limitations**: Cannot claim drug library prevents all medication errors
