# Market Research — Source PDFs

> _Demo sample data — not for clinical use._

Authoritative source documents for market research and user-needs traceability. Summary markdowns derived from these PDFs live one level up at `docs/project/input-analysis/market-research/`.

## Expected Content

- Strategic market and clinical analyses (PDF)
- User-needs assessments and design-input traceability reports (PDF)
- Published industry / analyst research (PDF)

## Conventions

- **Naming**: Verbatim filenames from the originating document (no rename). The sibling `.md` in the parent folder carries a `source:` frontmatter pointer to the PDF name in this folder.
- PDFs are authoritative; `.md` conversions in the parent folder are summary-fidelity only.
- Do not edit PDFs. Replace-only if a new revision supersedes the file — and then bump the parent `.md` changelog with the version diff.
