# Tool Validation

Validation records for software tools used in development and quality processes per IEC 62304 and FDA guidance. Covers compilers, test frameworks, static analysis tools, build systems, SOUP management tools, and any automated tools whose output affects device quality.

## Expected Content

- Tool validation plans
- Tool validation reports
- Tool risk assessments
- Tool inventory/registry
- Revalidation records

## Conventions

- **Naming**: `tool-name-validation.md` at root; matching `.docx` in `formal/`
- Link back to the originating task document
- Note date and source of any data or finding
