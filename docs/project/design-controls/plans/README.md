# Plans

Design and development plans, V&V plans, maintenance plans, and project strategy documents. These govern how the design control process is executed.

## Expected Content

- Software Development Plan
- V&V Plan
- Configuration Management Plan
- Maintenance Plan
- Project strategy docs

## Conventions

- **Naming**: `plan-type-name.md` at root; matching `.docx` in `formal/`
- Link back to the originating task document
- Note date and source of any data or finding
