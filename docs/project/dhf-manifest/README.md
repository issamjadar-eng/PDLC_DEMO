# `docs/project/dhf-manifest/` — DHF Manifest Outputs

**Generated outputs** from the `/dhf-manifest` skill — never hand-edited. The skill catalogs every DHF deliverable expected for the project's regulatory + QMS scope and reports presence / coverage / gaps.

Sibling to `/trace-matrix` (intra-DHF trace integrity); this skill answers "are the right documents present and do they satisfy regulation + QMS?"

## Structure

| File | What it is | Owner |
|------|------------|-------|
| `pdlc-demo-dhf-discovery.json` | Canonical-role → file-path resolution map across all 10 DHFs. Rebuilt by `/dhf-manifest discovery-index`. Consumed by `/advisors` (Tier-2 grounding) and `/medtech-docs render-sentinels`. | `/dhf-manifest discovery-index` |
| `pdlc-demo-dhf-manifest.json` | Full per-DHF obligation × evidence matrix with resolution status, gaps, and ambiguity notes. | `/dhf-manifest build` |
| `pdlc-demo-dhf-manifest.md` | Human-readable rendering of the same. | `/dhf-manifest build` |
| `pdlc-demo-dhf-by-section.md` | Section-view rollup. | `/dhf-manifest build` |
| `pdlc-demo-dhf-dashboard.md` | Compact compliance dashboard. | `/dhf-manifest dashboard` |
| `qms-manifest.json` / `qms-manifest.md` | QMS coverage view — links SOP/Form/WI IDs to DHF deliverables. | `/dhf-manifest build-qms` |

## Conventions

- **Do not hand-edit any file here.** All content is regenerated by the skill — manual edits will be silently overwritten on next build.
- File slug uses the project name from `project.yml project.name` (slugified). For PDLC_DEMO the slug is `pdlc-demo`. Renaming the project will change every filename here.
- The discovery JSON is committed (one canonical artifact per team checkout). Rebuilds happen post-pull or on demand via `/dhf-manifest discovery-index`.
- Gaps surfaced here are NOT regressions in the source DHFs — they're the input to `/gap-analysis`, `/tracker`, and human prioritization.

## For Claude

- To regenerate after structural changes (new DHFs, renamed folders, new canonical roles): `python3 .claude/skills/dhf-manifest/scripts/discovery-index.py` then `python3 .claude/skills/dhf-manifest/scripts/build-manifest.py`.
- Read `.claude/skills/dhf-manifest/SKILL.md` end-to-end before debugging unexpected gaps — discovery uses a layered patterns + frontmatter-opt-in resolution algorithm, and ambiguity_notes[] / gaps[] tell you exactly why a resolution failed.
