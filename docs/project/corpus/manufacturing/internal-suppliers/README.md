# Corpus dataset — `manufacturing/internal-suppliers`

_Demo sample data — not for clinical use._

**Demo-fabricated** approved-supplier register joined to monthly incoming-inspection
results, 2025-01 through 2026-08 (240 rows: 12 suppliers × 20 periods; data through
2026-08-31). Generated by the seeded `gen.py` (seed 42, no clocks) — the stand-in for
the approved-supplier list (ASL) + incoming-inspection log export. Register fields
(fictional name, component family, single-source flag, approval status, last / next
audit dates) repeat on every period row so each row is self-describing; period fields
are lots received / rejected, on-time %, and the period scorecard (A–D, computed from
reject rate and on-time). Component families: PCB, pump-motor, battery, enclosure,
tubing-set, display. Supplier ids are the ones cited by
`manufacturing/internal-ncr-capa` `supplier_id`.

**Narrative knobs seeded** (honest list — modeled, not observed; asserted by
`check_knobs.py`):

- **SUP-003 Meridian Drive Systems (pump-motor, single source)**: quality-system audit
  overdue at the horizon (next due 2025-11-15) and incoming reject rate rising through
  2026 (~2% in 2025 → ~9% in 2026-Q3), with on-time slipping from 2026-04. SUP-011 is
  a conditional, low-volume second source still in qualification — it does not relieve
  the exposure.
- **SUP-006 Halden Cell Works (battery)**: `approval_status: probation`, ~6% rejects,
  ~82% on-time — C/D scorecards in every period.
- **SUP-010 Lumen Display Group** is the other single-source supplier (display), healthy.
- Everyone else: ~1–1.5% rejects, 93–97% on-time, audits current.

**Consumed by**: MQ-05 (supplier quality — reject rate and on-time by supplier /
family, scorecard distribution, single-source exposure, audit currency); roadmap MQ-06
(obsolescence by hw rev).

## Conventions

- Managed by the `corpus` skill (`corpus.py`). Snapshots under `snapshots/` are immutable —
  never hand-edit; re-acquire instead. `dataset.yml` is the config; `latest` points at the
  newest valid snapshot. Assumptions in `assumptions/A-NNN.yml`, waivers in `waivers/W-NNN.yml`.
- Regenerate via `corpus.py acquire` — never edit CSVs. Generator is deterministic
  (seed 42, fixed `DATA_THROUGH` horizon, no clocks); `data_through: 2026-08-31` lands
  in provenance as `as_of`.
- Key is `[supplier_id, period]`; `single_source` is the string `true` / `false`.
