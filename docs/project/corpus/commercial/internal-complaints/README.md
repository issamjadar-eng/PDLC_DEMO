# Corpus dataset — `commercial/internal-complaints`

_Demo sample data — not for clinical use._

**Demo-fabricated** 18-month complaint log (430 records: category, severity 1–3, device
linkage, MDR-filed flag). Generated by seeded `gen.py` — stand-in for the
complaint-handling system export. Narrative: battery complaints skew PP3000/older
firmware; volumes trend upward over the window.

**Consumed by**: BQ-18 (trends vs thresholds), BQ-20 (signal watch), BQ-21 (MDR posture),
BQ-22 (closed loop), BQ-25 (upgrade-struggle correlation).

## Conventions

- Managed by the `corpus` skill (`corpus.py`). Snapshots under `snapshots/` are immutable —
  never hand-edit; re-acquire instead. `dataset.yml` is the config; `latest` points at the
  newest valid snapshot. Assumptions in `assumptions/A-NNN.yml`, waivers in `waivers/W-NNN.yml`.
