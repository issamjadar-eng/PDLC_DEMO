# Corpus dataset — `commercial/internal-subscriptions`

_Demo sample data — not for clinical use._

**Demo-fabricated** Cloud Suite subscription register: one row per subscribed site
(42 rows) with start date, connected-pump count, ARR, annual cost to serve, status, and
hardware discount. Generated by the seeded `gen.py` (seed 42) — the stand-in for a
subscription billing / entitlement export in a real deployment. `pumps_connected`
equals the shared fleet model's connected-device count per site exactly, so joins
against `internal-fleet` and `internal-telemetry-utilization` reconcile (identical
embedded fleet model, same seed).

**Consumed by**: BQ-04 (subscription economics / cost to serve), BQ-29 (attach rate —
the deliberate attach-gap sites are the unsubscribed-but-connected denominator).

## Narrative knobs (seeded, measured on snapshot 2026-07-27.2)

- **ARR ≈ $450/connected pump/yr** — per-site negotiated rate drawn 430..470.
- **Small sites disproportionately expensive** — cost to serve = $2,800/site floor +
  $150/pump + noise, breakeven ≈9-10 connected pumps. All 26 sites with ≤6 connected
  pumps run negative margin; all 10 sites with ≥12 pumps are profitable (median cost
  per pump: $971 small vs $343 large). Because the fleet's EMEA/APAC connected
  footprints are small, 30/42 sites are net-negative — the sub-scale-economics story.
- **Hardware-discount cannibalization signal** — subscribed sites average 5.9%
  hardware discount (gauss μ=6, σ=2.5, floored at 0).
- **Churn** — 3 churned sites: S-NA-01, S-NA-04, S-NA-11 (early 2024 starts).
- **Attach gap (BQ-29)** — 4 connected sites deliberately have NO subscription row:
  S-NA-21, S-EMEA-08, S-EMEA-13, S-APAC-08.

Only sites with ≥1 connected device can subscribe; the register is current-state as of
the snapshot (no clocks in the generator — all dates literal).

## Conventions

- Managed by the `corpus` skill (`corpus.py`). Snapshots under `snapshots/` are immutable —

  newest valid snapshot. Assumptions in `assumptions/A-NNN.yml`, waivers in `waivers/W-NNN.yml`.
- Regenerate via `corpus.py acquire` — never edit CSVs.
