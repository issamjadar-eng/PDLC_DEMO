# Corpus dataset — `commercial/internal-upgrade-campaign`

_Demo sample data — not for clinical use._

**Demo-fabricated** per-device telemetry for field-update campaign **C-2026-02** (PP3500
firmware → 3.4.0; 389 target devices): wave, remote/onsite method, status, completion
date, duration, tickets. Generated by seeded `gen.py` with deliberate narrative knobs:
**EMEA behind plan** (~50% vs NA ~77%), **failure cluster on hw_rev B upgrading from
3.1.2** (~23% fail/rollback vs ~4% baseline), remote only where Cloud Suite connected.

**Consumed by**: BQ-23 (coverage plan-vs-actual), BQ-24 (failure clusters / pause
trigger), BQ-25 (customer struggle), BQ-26 (capacity), BQ-30 (upgrade economics).

## Conventions

- Managed by the `corpus` skill (`corpus.py`). Snapshots under `snapshots/` are immutable —
  never hand-edit; re-acquire instead. `dataset.yml` is the config; `latest` points at the
  newest valid snapshot. Assumptions in `assumptions/A-NNN.yml`, waivers in `waivers/W-NNN.yml`.
