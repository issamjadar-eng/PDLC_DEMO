# Corpus dataset — `commercial/internal-fleet`

_Demo sample data — not for clinical use._

**Demo-fabricated** installed-base registry (884 devices: PP3500/PP3000 across 48 sites,
3 regions; hw rev, firmware, Cloud Suite connectivity). Generated by the seeded
`gen.py` (seed 42) — the stand-in for a Fleet Management / ERP export in a real
deployment. Device serials/sites align with the other `internal-*` datasets (identical
embedded fleet model, same seed).

**Consumed by**: BQ-11 (adoption divergence), BQ-23/27 (coverage + fleet currency),
BQ-29 (attach rate), and as the ONLY sanctioned denominator for internal complaint rates.

## Conventions

- Managed by the `corpus` skill (`corpus.py`). Snapshots under `snapshots/` are immutable —
  never hand-edit; re-acquire instead. `dataset.yml` is the config; `latest` points at the
  newest valid snapshot. Assumptions in `assumptions/A-NNN.yml`, waivers in `waivers/W-NNN.yml`.
- Regenerate via `corpus.py acquire` — never edit CSVs.
