# Corpus dataset — `finance/internal-standard-costs`

_Demo sample data — not for clinical use._

**Demo-fabricated** standard unit costs, 2024-Q1 through 2026-Q2 (160 rows: quarter ×
product line × revenue type), each with its material / labor / overhead split and the
standard version in force (`STD-YYYY.1` for H1, `.2` for H2). Generated by the seeded
`gen.py` (seed 42) — the stand-in for the ERP cost-accounting roll-up in a real
deployment. Product lines and revenue types are the `commercial/internal-financials`
vocabulary (IP5000, PP3000, PP3500, SP6000, SP6500, cloud-suite; hardware | consumables |
service | subscription) and the unit prices are that generator's constants, so a
standard expressed as ASP × ratio lands in the same per-unit dollars the financials'
`cogs_usd / units` produces. **Actual unit cost is deliberately not in this dataset** —
the standard-vs-actual variance is the join with `internal-financials`.

**Narrative knobs seeded** (honest list — modeled, not observed):

- PP3000 / IP5000 hardware: the standard starts 2 pts of ASP below the actual COGS
  ratio and is re-set upward only ~0.6 pt per quarter while the financials' actual
  ratio climbs ~1.2 pt/quarter — an **unfavorable variance that widens ~1 pt of
  standard per quarter** (≈ +3% in 2024-Q1 → ≈ +11% in 2026-Q2).
- PP3500 hardware: standard 0.535 of ASP against an actual of 0.52 — **favorable** every
  quarter (design-to-cost landed below standard).
- SP6000 / SP6500 hardware on standard; consumables, service and subscription carry small
  stable unfavorable gaps (≈ +1%).
- ±0.3% per-cell noise; no clocks — literal quarters, as-of 2026-08-31.
- The knob is **proven at acquire/validate** by `check_knobs.py` (the `asserts.command`
  seam): it reads the sibling `commercial/internal-financials` latest snapshot and fails
  unless legacy hardware is unfavorable-and-widening and PP3500 favorable. If the
  financials snapshot is refreshed with different anchors, this dataset's validate fails
  loudly rather than silently splitting the world.

**Consumed by**: FQ-01 (gross margin by line/region + standard-vs-actual cost variance);
roadmap FQ-02 (price/volume/mix bridge).

## Conventions

- Managed by the `corpus` skill (`corpus.py`). Snapshots under `snapshots/` are immutable —
  never hand-edit; re-acquire instead. `dataset.yml` is the config; `latest` points at the
  newest valid snapshot. Assumptions in `assumptions/A-NNN.yml`, waivers in `waivers/W-NNN.yml`.
- Regenerate via `corpus.py acquire` — never edit CSVs.
- Unit-price constants (`ASP_HW`, `ASP`) mirror `commercial/internal-financials/gen.py`
  — keep in sync if that generator's prices change (the knob check will fail if not).
