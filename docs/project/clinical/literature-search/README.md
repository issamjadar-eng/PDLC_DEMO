# Literature Search Strategies

> _Demo sample data — not for clinical use. Illustrative content for the PDLC_DEMO project (anchor product: PP3500 / PainEase PCA Advanced)._

This folder holds the literature search strategies used by the Clinical Evaluation Plans for PP3500. Strategies follow a **PRISMA**-style systematic-review structure (PICO framing, multiple databases, defined inclusion/exclusion, dual-reviewer screening) where applicable, and are documented per MEDDEV 2.7/1 Rev 4 expectations for traceable search records.

## Conventions

- File naming: `LSS-NNNN.md`.
- Frontmatter `doc_type: literature-search-strategy`.
- Each strategy must include: PICO, databases, search string, date range, PRISMA flow, screening process.
- Demo banner mandatory.
