# Clinical Evaluation Plans

> _Demo sample data — not for clinical use. Illustrative content for the PDLC_DEMO project (anchor product: PP3500 / PainEase PCA Advanced)._

Clinical Evaluation Plans (CEPs) define the scope, methodology, evaluators, data sources and acceptance criteria for the Clinical Evaluation Report (CER) of the PP3500 PainEase PCA Advanced. CEPs are written per **MDR 2017/745 Annex XIV** and **MEDDEV 2.7/1 Rev 4**, and reference the **FDA guidance on use of clinical data in 510(k) submissions** for the US pathway.

## Conventions

- File naming: `CEP-NNNN.md` at root with formal DOCX in `formal/` once promoted.
- All CEPs use the standard frontmatter schema (`doc_type: clinical-evaluation-plan`).
- Demo banner mandatory on line 3.
