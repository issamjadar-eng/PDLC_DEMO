# PMCF Plans

> _Demo sample data — not for clinical use. Illustrative content for the PDLC_DEMO project (anchor product: PP3500 / PainEase PCA Advanced)._

Post-Market Clinical Follow-up (PMCF) plans defined for the PP3500 in accordance with **MDR Article 83** and **Annex XIV Part B**. Each plan defines the objectives, methods, data sources, analyses, success criteria and reporting cadence used to generate ongoing clinical evidence after CE marking and 510(k) clearance.

## Current Contents

| File | Summary |
|---|---|
| `PMCF-1001.md` | Initial PMCF plan; multi-site cohort + registry; primary device PMCF |
| `PMCF-1002.md` | Updated v2.0 PMCF plan with provider/patient surveys and CRO registry |
| `PMCF-1003.md` | Long-term safety and performance plan; 50–100 patients/year registry |
| `PMCF-1004.md` | PMCF plan with literature surveillance and biennial searches |
| `PMCF-1005.md` | PMCF plan emphasising PROs and provider feedback |

## Conventions

- File naming: `PMCF-NNNN.md`.
- Frontmatter `doc_type: pmcf-plan`.
- Each plan must reference the corresponding CER and risk file row(s) it supports.
- Demo banner mandatory.
