# PMCF Studies

> _Demo sample data — not for clinical use. Illustrative content for the PDLC_DEMO project (anchor product: PP3500 / PainEase PCA Advanced)._

Records of the actual post-market clinical follow-up studies executed against the PMCF plans for the PP3500. Each study record captures governance (sponsor, PI, IRB), design and timeline, population, endpoints, statistical analysis plan, and findings. Studies are conducted per **ISO 14155:2020** for clinical investigations of medical devices.

## Conventions

- File naming: `STUDY-NNNN.md`.
- Frontmatter `doc_type: pmcf-study`.
- Each study cites its IRB approval, protocol version, and parent PMCF plan.
- Demo banner mandatory.
