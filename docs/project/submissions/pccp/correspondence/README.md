# PCCP Correspondence

FDA interactions specific to the PCCP. The PCCP is filed with the 510(k) but may generate separate correspondence if FDA has PCCP-specific questions. File in the most specific location — PCCP-specific here, general 510(k) in the 510k folder.

## Expected Content

- FDA PCCP feedback
- Responses to PCCP questions
- Outgoing PCCP correspondence

## Conventions

- **Naming**: `YYYY-MM-DD-type-topic.md` (e.g., `2026-07-01-fda-pccp-feedback.md`)
- Link back to the originating task document
- Note date and source of any data or finding
