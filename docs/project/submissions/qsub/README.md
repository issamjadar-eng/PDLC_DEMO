# Q-Sub (Pre-Submission)

Pre-Submission package for FDA engagement. Components: cover letter, device description, proposed intended use, predicate comparison, PCCP summary, specific questions.

## Expected Content

- Cover letter
- Device description
- Proposed intended use
- Predicate comparison
- PCCP summary
- FDA questions

## Conventions

- **Naming**: `component-name.md` at root; matching `.docx` in `formal/`
- Link back to the originating task document
- Note date and source of any data or finding
