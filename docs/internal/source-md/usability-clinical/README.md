## Conventions

- Doc IDs follow `GL-<TYPE>-UC-<NNN>`.
- Use-related hazards identified here feed the RMF (`../risk-management/`).
- Summative usability is an input to Design Validation (`../design-controls/`).
- CER updates are driven by PMS signals (`../post-market/`).
