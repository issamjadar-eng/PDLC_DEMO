- Doc IDs follow `GL-<TYPE>-PM-<NNN>`.
- Reportable events flow through GL-SOP-PM-003 with jurisdictional timelines.
- PMS signals trigger: RMF update (`../risk-management/`), CER update (`../usability-clinical/`), CAPA (`../quality-management/`), design change (`../design-controls/`).
