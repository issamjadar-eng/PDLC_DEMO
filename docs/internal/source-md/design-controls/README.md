## Conventions

- Doc IDs follow `GL-<TYPE>-DC-<NNN>`.
- SOPs reference ISO / FDA clauses by number; templates reference their parent SOP.
- Templates/forms under `templates/` are fillable markdown stubs with `{{PLACEHOLDER}}` tokens.
