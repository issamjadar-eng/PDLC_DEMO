# Source — Markdown Conversions

Markdown conversions of the original source documents from `source/`. These are machine-readable versions used for AI-assisted analysis, cross-referencing, and distillation into project-specific guidance.

## Expected Content

- Markdown conversions of SOPs, WIs, policies, and templates from `../source/`
- One `.md` file per source document

## Conventions

- **Naming**: Match the original filename with `.md` extension (e.g., `SOP-001-Design-Controls.pdf` → `SOP-001-Design-Controls.md`)
- Preserve the structure and content of the original — do not editorialize
- Note conversion date and method (manual, AI-assisted, OCR) at the top of the file
- Flag any content that could not be accurately converted with `[VERIFY]` markers
