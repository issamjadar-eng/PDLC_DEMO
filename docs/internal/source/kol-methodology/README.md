# KOL Methodology — Source PDFs

> _Demo sample data — not for clinical use._

Reference documents on Key Opinion Leader (KOL) methodology — how we structure KOL engagements, assess preferences, and operate role-playing language agents grounded on clinician personas.

## Expected Content

- Methodology frameworks (PDF) — KOL personality assessment, role-playing language agent design
- Process descriptions for KOL selection, engagement, and preference capture
- Any supporting analyst / academic literature used to anchor the internal process

## Conventions

- **Naming**: Verbatim filenames from the originating document (no rename).
- This is a source folder (`docs/internal/source/` tier) — the authoritative PDFs are here; distilled markdown lives under `docs/internal/source-md/` once processed via `/docflow convert`.
- Keep personal identifying information about specific KOLs out of these documents. If a document references individuals by name, redact before commit.
- Link any derived process docs, templates, or dashboards back to the source file they draw from.
