# TC-PROTO-GROUNDING · run 1 · q1 · advisor: regulatory-affairs · 2026-09-08 · model claude-fable-5-1

**Question (verbatim):** Which predicate does the lead device claim substantial equivalence to, and where is the comparison documented?

**Answer (verbatim capture):**

**Short answer:** The lead device, PP3500 (PainEase PCA Advanced, K210345), claims substantial equivalence to its own predecessor **PP3000 (PainEase PCA), K190567**. The predicate identity is documented consistently across the strategy, the DHF, the input-analysis records, and the submission drafts — but there is **no formal side-by-side SE comparison table anywhere in the repo yet**. The closest thing to a comparison is the "Comparative Claims" and "Predicate Device" sections inside the PP3500 device record.
