## Strategy Content

<!-- STRATEGY CONTENT: development, operations -->
**Naming convention for sibling-program docs (2026-05-30):** when a project hosts overview docs for multiple device programs, name them by program ID — `project-overview.md` for the canonical demo lead, `project-overview-<programID>.md` for siblings (e.g., `project-overview-sp6500.md`). Avoid numeric suffixes (`-2`, `-3`) — they read as version numbers, not as program IDs, and create the exact confusion the user surfaced today.
