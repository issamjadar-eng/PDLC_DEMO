Task iThe task this row covers. Top line: a short summary. Bottom line: owner · task number. Last updated iMost recent date recorded in the task document. Category iThe by-hand specialist persona(s) this work maps to — its cost category (e.g. rd-lead, regulatory-affairs). Agentic (hrs) iHuman supervised-attention hours — the hands-on + active-review labor you put in. Not machine compute (see Agentic $), and not time agents ran unattended in the background. Counted as attention, so it sums honestly across tasks. By-hand (hrs) iEstimated specialist person-hours to do the same work by hand — a labor sum across specialists, as a min–max range. Hours saved iBy-hand person-hours − agentic supervised hours — the human labor avoided, as a range. Agentic $ (tokens) iMeasured token cost of the agentic run at API list prices — the machine-compute cost, separate from the human hours.
