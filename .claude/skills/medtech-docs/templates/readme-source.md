# Source Documents

Original SOP, procedure, template, and policy files in their native format (PDF, DOCX, XLSX). These are the authoritative source documents — do not modify them here. Markdown conversions go in `source-md/`.

## Expected Content

- Standard Operating Procedures (SOPs)
- Work Instructions (WIs)
- Policy documents
- Form templates
- Quality Management System (QMS) documents

## Conventions

- **Naming**: Preserve the original filename from the source system
- Do not rename or modify source files — they are reference copies
- Every file here should have a corresponding markdown conversion in `../source-md/`
- Note the date the file was obtained and its source system
